§1

Fundamentos de LaTeX

Antes de escribir una sola línea, conviene entender qué es LaTeX y en qué se diferencia radicalmente de Word o LibreOffice.

¿Qué es LaTeX?

LaTeX (pronunciado «lá-tech» o «léi-tech») es un sistema de composición de documentos de alta calidad, ampliamente utilizado en el ámbito académico y científico.

AspectoLaTeXWord / LibreOffice
ParadigmaProgramación (código → compilar → PDF)WYSIWYG
EnfoqueContenido y estructuraFormato y apariencia
ControlTotal sobre el diseñoLimitado por la interfaz
MatemáticasExcelente (nativo)Deficiente (requiere complementos)

El flujo de trabajo

Todo documento LaTeX sigue el mismo ciclo, tantas veces como haga falta:

[ESCRIBIR]  →  .tex (código fuente)
      ↓
[COMPILAR]  →  pdflatex, xelatex, lualatex
      ↓
 ¿ERRORES?  →  Sí → corregir y volver a compilar
      ↓
[VISUALIZAR] → PDF (documento final)
      ↓
[DEPURAR]   →  ajustar y repetir si es necesario

Objetivos de aprendizaje

Al completar esta guía, serás capaz de:

  • Crear documentos LaTeX desde cero
  • Estructurar contenido con secciones y estilos
  • Escribir fórmulas matemáticas complejas
  • Insertar tablas, imágenes y listas
  • Gestionar referencias y bibliografía
  • Compilar documentos y resolver errores básicos
  • Personalizar el formato de tus documentos

§2

Estructura y sintaxis

Todo documento LaTeX comparte un esqueleto mínimo y una gramática de comandos que se repite en toda la guía. Domina esto y el resto es vocabulario.

Estructura mínima

\documentclass{article}    % Tipo de documento (PREÁMBULO)
\usepackage[utf8]{inputenc} % Configuración

\begin{document}           % INICIO DEL CUERPO
% Aquí va el contenido visible
\end{document}             % FIN DEL CUERPO

Anatomía de un comando

Todos los comandos de LaTeX comparten esta forma. Toca cada parte para ver qué hace:

\comando[opciones]{argumento1}{argumento2}
Toca cualquier parte del comando de arriba para ver su función.
EJEMPLO: \includegraphics[width=5cm]{imagen.png}

Comentarios

% Esto es un comentario (no aparece en el PDF)
\documentclass{article} % Comentario al final de línea
% \usepackage{algo}     % Línea desactivada

§3

Texto básico

El formato de texto en LaTeX se marca con comandos explícitos, no con botones. Esto obliga a pensar en estructura semántica antes que en apariencia.

Formato de texto

\textbf{Negrita}      % NEGRITA
\textit{Cursiva}      % Cursiva
\underline{Subrayado} % Subrayado
\textsc{Versalitas}   % VERSALITAS
\emph{Énfasis}         % Énfasis (generalmente cursiva)

Tamaños de fuente

{\tiny Texto minúsculo}
{\scriptsize Texto muy pequeño}
{\footnotesize Texto pie de página}
{\small Texto pequeño}
{\normalsize Texto normal}
{\large Texto grande}
{\Large Texto más grande}
{\LARGE Texto muy grande}
{\huge Texto enorme}
{\Huge Texto gigante}

Espaciado

\\                    % Salto de línea
\newline              % Salto de línea (similar)
\par                  % Nuevo párrafo

\newpage              % Nueva página
\clearpage            % Nueva página (fuerza salida de flotantes)

\hspace{1cm}          % Espacio horizontal
\vspace{1cm}          % Espacio vertical

\quad                 % Espacio de 1em
\qquad                % Espacio de 2em

~                     % Espacio no separable (evita salto de línea)

Estructura del documento

\section{Sección Principal}
\subsection{Subsección}
\subsubsection{Sub-subsección}
\paragraph{Párrafo con título}
\subparagraph{Subpárrafo}

% Sin numeración (versión con *)
\section*{Sección sin numerar}

Entornos especiales

\begin{center}
  Texto centrado
\end{center}

\begin{flushleft}
  Texto alineado a la izquierda
\end{flushleft}

\begin{flushright}
  Texto alineado a la derecha
\end{flushright}

\begin{quote}
  Cita textual (con sangría)
\end{quote}
§4

Matemáticas

Aquí es donde LaTeX brilla frente a cualquier procesador de texto: escribir ecuaciones se vuelve tan natural como escribir texto.

Modos matemáticos

% En línea (dentro del párrafo)
La fórmula $E = mc^2$ es famosa.

% En display (ecuación en su propia línea)
\[ E = mc^2 \]

% Ecuación numerada
\begin{equation}
  E = mc^2
\end{equation}

% Múltiples ecuaciones alineadas
\begin{align}
  a + b &= c \\
  d + e &= f
\end{align}

Superíndices y subíndices

$x^2$      % x al cuadrado
$x^{10}$   % x a la 10 (agrupar con {})
$x_i$      % x sub i
$x_{ij}$   % x sub ij
$x^2_i$    % x sub i al cuadrado (orden: subíndice después del superíndice)

Fracciones y raíces

\frac{numerador}{denominador}           % Fracción
\frac{1}{2}                             % 1/2

\sqrt{radicando}                        % Raíz cuadrada
\sqrt[3]{radicando}                     % Raíz cúbica
\sqrt[4]{16} = 2                        % Raíz cuarta

Delimitadores

( )        % Paréntesis normales
[ ]        % Corchetes
\{ \}      % Llaves (escapadas con \)
|          % Barra vertical
\|         % Doble barra (norma)

\left( \frac{a}{b} \right)  % Tamaño automático
\left[ \frac{a}{b} \right]
\left\{ \frac{a}{b} \right\}

§5

Listas y tablas

Estructurar información en listas y tablas es una de las tareas más frecuentes al redactar cualquier documento técnico.

Listas

% No numerada (viñetas)
\begin{itemize}
  \item Primer elemento
  \item Segundo elemento
  \begin{itemize}  % Sublista
    \item Subelemento 1
    \item Subelemento 2
  \end{itemize}
  \item Tercer elemento
\end{itemize}

% Numerada automáticamente
\begin{enumerate}
  \item Primer elemento
  \item Segundo elemento
  \begin{enumerate}  % Sublista
    \item Subelemento 1
    \item Subelemento 2
  \end{enumerate}
  \item Tercer elemento
\end{enumerate}

% Lista de descripción
\begin{description}
  \item[Término 1] Definición del término
  \item[Término 2] Definición del término
\end{description}

Tablas básicas

\begin{tabular}{|l|c|r|}  % Columnas: izquierda, centro, derecha
  \hline                   % Línea horizontal
  Columna 1 & Columna 2 & Columna 3 \\
  \hline
  Izquierda & Centro & Derecha \\
  \hline
\end{tabular}
SímboloAlineación
lIzquierda
cCentrado
rDerecha
p{3cm}Ancho fijo (justificado)
|Línea vertical
\hlineLínea horizontal

Tablas avanzadas

% Combinar columnas (2 columnas → 1)
\begin{tabular}{|l|l|}
  \hline
  \multicolumn{2}{|c|}{Productos} \\
  \hline
  Manzanas & 2.50 € \\
  Naranjas & 3.00 € \\

\end{tabular}

  \hline
\end{tabular}

% \usepackage{tabularx}
\begin{tabularx}{\textwidth}{|X|X|}
  \hline
  Columna flexible & Columna flexible \\
  \hline

Imágenes y flotantes

    
Las imágenes en LaTeX no se «pegan» donde escribes: viajan como elementos flotantes que el sistema recoloca según el espacio disponible.

% Comandos

\includegraphics[width=5cm]{imagen.png}
\includegraphics[width=0.5\textwidth]{imagen.png}
\includegraphics[height=3cm]{imagen.png}
\includegraphics[scale=0.5]{imagen.png}

% Opciones de ancho
0.3\textwidth    % 30% del ancho del texto
0.5\linewidth    % 50% del ancho de línea actual
0.7\columnwidth  % 70% del ancho de columna

§7
Referencias y bibliografía

    
Etiquetar y referenciar es lo que convierte un documento largo en algo navegable — y lo que hace que «Figura 3» siga siendo correcto aunque reordenes el contenido.


    
Referencias cruzadas

    

      
% 1. Etiquetar el elemento
\begin{figure}[h]
  \centering
  \includegraphics{imagen.pdf}
  \caption{Descripción}
  \label{fig:diagrama}  % ¡Clave!
\end{figure}

% 2. Referenciar en el texto
Como se muestra en la Figura \ref{fig:diagrama}...

% Con hyperref (crea enlace clickable)
\usepackage{hyperref}
... en la Figura \ref{fig:diagrama} en la página \pageref{fig:diagrama}.

fig:Figuras

        
tab:Tablas

        
eq:Ecuaciones

Bibliografía con thebibliography

    

      
\begin{thebibliography}{9}  % {9} = ancho máximo de etiqueta

  Knuth, Donald E. (1984). 
  \textit{The TeXbook}. 
  Addison-Wesley.

  \bibitem{lamport94}
  Lamport, Leslie (1994). 
  \textit{LaTeX: A Document Preparation System}. 
  Addison-Wesley, 2nd edition.
\end{thebibliography}

% Cita en el texto

Bibliografía con BibTeX (recomendado)

    

      
% 1. Crear archivo .bib (ej: referencias.bib)
@book{knuth84,
  author    = {Donald E. Knuth},
  title     = {The TeXbook},
  publisher = {Addison-Wesley},
  year      = {1984}
}

@article{lamport94,
  author  = {Leslie Lamport},
  title   = {LaTeX: A Document Preparation System},
  journal = {Communications of the ACM},
  volume  = {37},
  number  = {2},
  pages   = {80-87},
  year    = {1994}
}

% 2. En el documento:
\bibliographystyle{plain}  % Estilo de citación
\bibliography{referencias}  % Archivo .bib

% 3. Citar en el texto
\cite{knuth84} y \cite{lamport94}

§10
Actividades prácticas

    
Seis actividades progresivas, de un documento simple a un informe académico completo. Intenta resolver cada una antes de mirar las pistas.


    

      
Actividad 1 — Mi primer documento completo
+

      

        
Objetivo: Crear un artículo con estructura completa y formato básico.

        
Enunciado: Crea un documento que:

        
    
          
  • Sea de clase article
    • 
          
  • Use codificación UTF-8 e idioma español
    • 
          
  • Tenga título, autor y fecha
    • 
          
  • Incluya al menos 3 secciones y 2 subsecciones
    • 
          
  • Contenga texto con formato: negrita, cursiva y subrayado
    • 
          
  • Incluya un comentario en el código
    • 
        

        
        
        

          
    
            
  1. Escribe la estructura mínima: \documentclass, preámbulo, \begin{document}
    2. 
            
  2. Añade \title{}, \author{}, \date{}
    3. 
            
  3. Usa \maketitle en el cuerpo
    4. 
            
  4. Crea secciones con \section{} y \subsection{}
    5. 
            
  5. Agrega formato con \textbf{}, \textit{}, \underline{}
    6. 
            
  6. Añade comentarios con %
    7. 
          

        

        

          
\documentclass{article}
\usepackage[utf8]{inputenc}
\usepackage[spanish]{babel}

% Título y autor
\title{Introducción a LaTeX}
\author{Carlos Martínez}
\date{1 de septiembre de 2024}

\begin{document}

\maketitle

\section{Primeros pasos}
Esta es la \textbf{introducción} al documento.
\subsection{Formato básico}
Podemos usar \textit{cursiva} y \underline{subrayado}.

\section{Sección principal}
Este es el contenido principal del artículo.
\subsection{Subsección detallada}
Aquí se detalla la información de la sección anterior.

\section{Conclusiones}
Finalizamos el documento con las conclusiones.

\end{document}

        

      

    


    

      
Actividad 2 — Fórmulas matemáticas
+

      

        
Objetivo: Practicar ecuaciones complejas en modo matemático.

        
Enunciado: Escribe las siguientes expresiones en LaTeX:

        
    
          
  1. La fórmula del área del círculo: πr² (en línea)
    2. 
          
  2. La fórmula cuadrática en display: x = (−b ± √(b²−4ac)) / (2a)
    3. 
          
  3. Un sistema de ecuaciones alineado: 2x + 3y = 7, 4x − y = 5
    4. 
          
  4. La serie infinita: ∑(n=1 hasta ∞) 1/n² = π²/6
    5. 
          
  5. Una matriz 2×2 con paréntesis
    6. 
        

        
        
        

          
    
            
  1. Usa \pi para π y ^2 para cuadrado
    2. 
            
  2. Para la fórmula cuadrática, usa \frac{} y \sqrt{}
    3. 
            
  3. El sistema necesita \begin{align} y & para alinear
    4. 
            
  4. La serie usa \sum con límites superior e inferior
    5. 
            
  5. La matriz usa \begin{pmatrix} y & para columnas
    6. 
          

        

        

          
\documentclass{article}
\usepackage[utf8]{inputenc}
\usepackage{amsmath, amssymb}

\begin{document}

\section{Área del círculo}
El área de un círculo es $A = \pi r^2$.

\section{Fórmula cuadrática}
La ecuación cuadrática se resuelve con:
\[

\section{Matriz}
