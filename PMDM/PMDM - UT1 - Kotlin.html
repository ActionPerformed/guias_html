01

Introducción y configuración

Por qué Kotlin ha ganado terreno en Android y qué necesitas instalado antes de escribir la primera línea.

¿Por qué Kotlin?

  • Lenguaje oficial para Android desde 2019.
  • 100% interoperable con Java.
  • Null Safety: el compilador evita NullPointerException.
  • Conciso: reduce el código repetitivo (boilerplate) ~40% frente a Java.
  • Moderno: combina programación orientada a objetos y funcional.

Comparativa Java vs Kotlin

    public String getNombre() { return nombre; }

Programación funcional y colecciones

Lambdas, listas, mapas y los operadores que convierten cinco líneas de bucles en una sola cadena legible.

Sintaxis de lambda:

val suma: (Int, Int) -> Int = { a, b -> a + b }
val cuadrado: (Int) -> Int = { it * it }  // "it" cuando hay un solo parámetro

Función que recibe lambda:

fun operar(a: Int, b: Int, operacion: (Int, Int) -> Int): Int {
    return operacion(a, b)
}

// Uso
val resultado = operar(5, 3) { x, y -> x * y }  // 15
// Listas
val listaInmutable = listOf("A", "B", "C")
val listaMutable = mutableListOf(1, 2, 3)
listaMutable.add(4)

// Mapas
val mapaInmutable = mapOf("clave1" to "valor1", "clave2" to "valor2")

mapaMutable["edad"] = "25"

// Sets (sin duplicados)
val setInmutable = setOf(1, 2, 3, 3)  // {1, 2, 3}
val alumnos = listOf("Ana", "Bea", "Carlos", "Ana", "David")

// filter: Filtra elementos
val conA = alumnos.filter { it.startsWith("A") }  // ["Ana", "Ana"]

// map: Transforma elementos
val enMayusculas = alumnos.map { it.uppercase() }  // ["ANA", "BEA", ...]

// forEach: Itera sin retorno
alumnos.forEach { println(it) }

// firstOrNull: Busca el primero que cumple

// sortedBy: Ordena por criterio
val ordenados = alumnos.sortedBy { it.length }

// take / drop: Paginación
val primeros3 = alumnos.take(3)  // Primeros 3
val sinPrimeros2 = alumnos.drop(2)  // Quita los 2 primeros
// flatMap: Aplana listas de listas

val aplanada = listas.flatMap { it }  // [1, 2, 3, 4]

// associate: Convierte lista a mapa

// {"Ana"=3, "Bea"=3, "Carlos"=6, "David"=5}

// groupBy: Agrupa elementos por clave
val porLongitud = alumnos.groupBy { it.length }
// {3=["Ana", "Bea"], 6=["Carlos"], 5=["David"]}
val numeros = listOf(2, 4, 6, 8)

numeros.any { it > 5 }   // true (hay algún >5)
numeros.all { it % 2 == 0 }  // true (todos pares)

Optimización para operaciones encadenadas:

// Con listas (Eager): ejecuta todas las operaciones
val listaResultado = lista
    .filter { it > 5 }   // Crea lista intermedia
    .map { it * 2 }      // Crea otra lista
    .take(3)

// Con secuencias (Lazy): ejecuta solo cuando se necesita
val secuenciaResultado = lista.asSequence()

    .map { it * 2 }

Manejo de excepciones

En Kotlin, try también puede ser una expresión, y runCatching lleva ese estilo funcional hasta el manejo de errores.

try-catch como expresión

val resultado = try {
    val numero = "123".toInt()
    numero * 2
} catch (e: NumberFormatException) {
    -1  // Valor por defecto si falla
}

runCatching (funcional)

val resultado = runCatching {
    "abc".toInt()  // Lanza excepción
}.getOrElse {
    -1  // Valor por defecto
}

// Otros métodos útiles
val exito = runCatching { 42 }
    .getOrNull()  // null si falla

val mensaje = runCatching { "123".toInt() }
    .fold(
        onSuccess = { "Éxito: $it" },
        onFailure = { "Error: ${it.message}" }
    )
Tip: runCatching devuelve un Result<T>, así que encaja bien en cadenas funcionales donde no quieres romper el flujo con un try/catch tradicional.

Corrutinas — asincronía moderna

La forma en la que Kotlin resuelve las operaciones que tardan (red, disco, temporizadores) sin bloquear el hilo principal ni encadenar callbacks.

// build.gradle.kts
dependencies {
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-core:1.7.3")
    implementation("org.jetbrains.kotlinx:kotlinx-coroutines-android:1.7.3")
}

Conceptos básicos

ConceptoDescripción
suspendFunción que puede pausarse y reanudarse
CoroutineScopeÁmbito de vida de las corrutinas
DispatchersHilo donde se ejecuta (Main, IO, Default)
JobRepresenta una tarea cancelable
launchLanza corrutina sin retorno
asyncLanza corrutina con retorno (Deferred)

launch vs async

import kotlinx.coroutines.*

// Función suspendida
suspend fun obtenerDatos(): String {
    delay(1000)  // Simula operación lenta
    return "Datos cargados"
}

fun main() = runBlocking {
    // launch: sin retorno
    val job = launch(Dispatchers.IO) {
        val datos = obtenerDatos()
        println("Resultado: $datos")
    }
    job.join()  // Espera a que termine

    // async: con retorno
    val deferred = async(Dispatchers.IO) {
        obtenerDatos()
    }
    val resultado = deferred.await()
    println(resultado)
}

Manejo de errores

fun main() = runBlocking {
    val handler = CoroutineExceptionHandler { _, exception ->
        println("Error capturado: ${exception.message}")
    }
    val job = launch(handler) {
        throw RuntimeException("Error en corrutina")
    }
    job.join()
}

En Android (viewModelScope)

class MiViewModel : ViewModel() {

Filtrado avanzado

Dada una lista de nombres, filtra los que tienen más de 3 letras, conviértelos a mayúsculas y ordénalos alfabéticamente.

Usa filter { }, map { }, sortedBy { } en cadena.
fun main() {
    val nombres = listOf("Ana", "Bea", "Carlos", "Lu", "David", "Eva")
    val resultado = nombres
        .filter { it.length > 3 }
        .map { it.uppercase() }
        .sortedBy { it }
    println(resultado)  // [CARLOS, DAVID]
}

Mapa de estudiantes

Crea un mapa Map<String, Double> con nombres y notas. Filtra los aprobados (>=5) y devuelve una lista de nombres ordenados por nota descendente.

Usa .filter { } sobre el mapa y sortedByDescending { }.
fun main() {
    val notas = mapOf("Ana" to 8.5, "Luis" to 4.5, "Eva" to 7.0, "Juan" to 5.5)
    val aprobados = notas
        .filter { it.value >= 5 }
        .entries
        .sortedByDescending { it.value }
        .map { it.key }
    println(aprobados)  // [Ana, Eva, Juan]
}

Función de orden superior con repetición

Crea una función repetirCondicional que reciba un número n y una lambda, y ejecute la lambda mientras n sea mayor que 0, decrementando n en cada iteración.

Usa un bucle while o do-while.
fun repetirCondicional(n: Int, accion: (Int) -> Unit) {
    var contador = n
    while (contador > 0) {
        accion(contador)
        contador--
    }
}

fun main() {
    repetirCondicional(5) { println("Iteración: $it") }
}

Data class y null safety

Define una data class Producto(id: Int, nombre: String, precio: Double). Dada una lista nullable, calcula el precio total de los productos no nulos que empiezan por «P».

Usa .filterNotNull(), .filter { } y .sumOf { }.
data class Producto(val id: Int, val nombre: String, val precio: Double)

fun main() {
    val productos: List<Producto?> = listOf(
        Producto(1, "Pan", 0.8), null, Producto(2, "Pasta", 1.2),
        Producto(3, "Leche", 1.5), null, Producto(4, "Pizza", 3.0)

    val total = productos
        .filterNotNull()
        .filter { it.nombre.startsWith("P") }
        .sumOf { it.precio }
    println("Total productos P: $total")  // Total productos P: 5.0
}

Extensión de String avanzada

Crea una función de extensión toInitials() para String que devuelva las iniciales de cada palabra en mayúscula (ej: «Ana María Pérez» → «A.M.P.»).

Usa .split(" ") y .map { it.first() }.
fun String.toInitials(): String {
    return this.split(" ")
        .filter { it.isNotEmpty() }
        .map { it.first().uppercase() }
        .joinToString(".") + "."
}

fun main() {
    val nombre = "ana maría pérez"
    println(nombre.toInitials())  // A.M.P.
}

Sealed class y when

Modela el estado de una descarga con una sealed class que tenga estados: Iniciada, Progreso(Int) (porcentaje), Completada(ByteArray), Error(String). Crea una función que maneje cada estado.

Usa is y when para manejar cada estado.
sealed class EstadoDescarga {
    object Iniciada : EstadoDescarga()
    data class Progreso(val porcentaje: Int) : EstadoDescarga()
    data class Completada(val datos: ByteArray) : EstadoDescarga()
    data class Error(val mensaje: String) : EstadoDescarga()
}

fun manejarDescarga(estado: EstadoDescarga) {
    when (estado) {
        EstadoDescarga.Iniciada -> println("Descarga iniciada")
        is EstadoDescarga.Progreso -> println("Progreso: ${estado.porcentaje}%")
        is EstadoDescarga.Completada -> println("Descarga completada: ${estado.datos.size} bytes")
        is EstadoDescarga.Error -> println("Error: ${estado.mensaje}")
    }
}

fun main() {
    manejarDescarga(EstadoDescarga.Iniciada)
    manejarDescarga(EstadoDescarga.Progreso(50))
}

Operadores de colecciones

Dada una lista de enteros del 1 al 20, obtén una lista con los pares, multiplícalos por 2, y agrupa por decenas (0-9, 10-19, 20-29).

Usa .filter { }, .map { } y .groupBy { }.
fun main() {
    val numeros = (1..20).toList()
    val resultado = numeros
        .filter { it % 2 == 0 }
        .map { it * 2 }
        .groupBy {
            when (it) {
                in 0..9 -> "0-9"
                in 10..19 -> "10-19"
                in 20..29 -> "20-29"
                else -> "Otros"
            }
        }
    println(resultado)
    // {0-9=[4, 8, 12, 16], 10-19=[20, 24, 28, 32, 36], 20-29=[40]}
}

ViewModel simulado

Simula un ViewModel con un StateFlow que maneje el estado de carga de datos. Crea una función cargarDatos() que emita estados de carga, éxito y error.

Usa un sealed class para estados y MutableStateFlow.
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*

sealed class EstadoDatos {
    object Cargando : EstadoDatos()
    data class Exito(val datos: List<String>) : EstadoDatos()
    data class Error(val mensaje: String) : EstadoDatos()
}

class SimuladorViewModel {
    private val _estado = MutableStateFlow<EstadoDatos>(EstadoDatos.Cargando)
    val estado: StateFlow<EstadoDatos> = _estado.asStateFlow()

    fun cargarDatos() {
        _estado.value = EstadoDatos.Cargando
        try {
            val datos = listOf("Elemento 1", "Elemento 2", "Elemento 3")
            _estado.value = EstadoDatos.Exito(datos)
        } catch (e: Exception) {
            _estado.value = EstadoDatos.Error(e.message ?: "Error desconocido")
        }
    }
}

fun main() = runBlocking {
    val vm = SimuladorViewModel()
    vm.cargarDatos()

    vm.estado.collect { estado ->
        when (estado) {
            EstadoDatos.Cargando -> println("Cargando...")
            is EstadoDatos.Exito -> println("Datos: ${estado.datos}")
            is EstadoDatos.Error -> println("Error: ${estado.mensaje}")
        }
    }
}

Esqueleto base

data class Producto(val id: Int, val nombre: String, val precio: Double, val categoria: String)

class RepositorioProductos {
    private val productos = listOf(/* ... */)

    suspend fun obtenerPorCategoria(categoria: String): List<Producto> {
        delay(500)
        return productos.filter { it.categoria == categoria }
    }

    suspend fun aplicarDescuento(categoria: String, porcentaje: Double): List<Producto> {
        delay(500)
        return productos.map {
            if (it.categoria == categoria)
                it.copy(precio = it.precio * (1 - porcentaje/100))
            else it
        }
    }
}
