Contexto y objetivos

Esta actividad es tu primer contacto real con el desarrollo Android. Partiendo del proyecto «Empty Activity», irás modificando la app paso a paso para entender cómo se conecta todo: no se trata de crear algo complejo, sino de perder el miedo al entorno.

Al terminar serás capaz de...

  1. Identificar los elementos principales de la interfaz de Android Studio.
  2. Explicar el flujo de arranque de una app Android.
  3. Modificar el código de MainActivity.kt para personalizar la interfaz.
  4. Usar @Preview para previsualizar composables sin ejecutar la app.
  5. Crear y gestionar un AVD para probar la app.
  6. Añadir interactividad básica con estado (remember + mutableStateOf).
  7. Consultar Logcat para diagnosticar errores.
  8. Documentar el proceso seguido.

Requisitos previos

  • Android Studio instalado y configurado.
  • JDK configurado (el que trae Android Studio por defecto).
  • Un AVD creado y funcionando.
  • Conocimientos básicos de programación (variables, funciones, condicionales).
  • Nociones básicas de Kotlin (o disposición a aprenderlo sobre la marcha).

    verticalArrangement = Arrangement.spacedBy(8.dp)

Extra

  
Adaptaciones para el aula

  

    
👥 Alumnos con menos base
Trabajar en parejas y centrarse en los bloques 1-3, dejando los retos extra como opcionales.

    
🚀 Alumnos avanzados
Añadir un tercer botón que cambie el color de fondo de la app, o usar LaunchedEffect para mostrar un mensaje al arrancar.

    
📵 Sin emulador
Usar un móvil físico por USB (activando depuración USB).

    
📡 Sin conexión
Usar el USB preparado con el SDK y las dependencias de Gradle.
