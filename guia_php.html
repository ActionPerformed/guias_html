01

Configuración y depuración

Antes de escribir una sola línea de lógica, el entorno tiene que decirte la verdad cuando algo falla.

En desarrollo quieres ver todos los errores; en producción, ninguno visible para el usuario.

php.ini
display_errors = On
error_reporting = E_ALL
date.timezone = "Europe/Madrid"
php
<?php
// Muestra tipo y valor de una variable
var_dump($variable);

// Muestra solo valor (para arrays/objetos legibles)
print_r($array);

// Registra error en log del servidor (útil en producción)
error_log("Mensaje de depuración", 0);
?>
var_dump() es tu mejor amigo cuando algo "no debería estar vacío" y lo está.
obligatorio en proyectos modernos
php
<?php
declare(strict_types=1);
// A partir de aquí, PHP respeta los tipos estrictamente
?>

    // Devuelve array o null

php

            
<?php
$numeros = [1, 2, 3, 4, 5];

// array_map: aplica función a cada elemento
$cuadrados = array_map(fn($n) => $n * $n, $numeros);

// array_filter: filtra elementos (mantiene true)
$pares = array_filter($numeros, fn($n) => $n % 2 === 0);

// array_reduce: reduce a un solo valor
$suma = array_reduce($numeros, fn($ac, $n) => $ac + $n, 0);

// Extra: array_column (para extraer columna de array asociativo)
$nombres = array_column($alumnos, 'nombre');

04
Seguridad en PHP

      
El bloque que más se penaliza si se olvida en un proyecto de evaluación: XSS, validación, contraseñas y CSRF.


      
⚠️
Ninguna de estas medidas es "opcional según el proyecto": son la base mínima para entregar cualquier formulario o panel con datos de usuarios.


      

        
        

          

            
php

            
<?php
// SIEMPRE usar al mostrar datos del usuario en HTML
// Ejemplo: $usuarioInput = '<script>alert(1)</script>'
echo htmlspecialchars($usuarioInput, ENT_QUOTES, 'UTF-8');

// Ejemplo en contexto HTML
<input value="<?= htmlspecialchars($nombre, ENT_QUOTES, 'UTF-8') ?>">
?>

            
▶ Salida (simulada, con un intento de inyección como entrada)

          

          
💡
Fíjate en la salida: los caracteres < > se convierten en entidades HTML, así que el navegador los muestra como texto y no como una etiqueta ejecutable.

        

      


      

        
        

          

            
php

            
<?php
// Validar email
$email = $_POST['email'] ?? '';
if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
    echo "Email válido";
}

// Validar número entero
$edad = filter_input(INPUT_POST, 'edad', FILTER_VALIDATE_INT);
if ($edad !== false && $edad >= 18) {
    echo "Mayor de edad";
}

// Sanitizar (limpiar) entrada
$nombre = filter_input(INPUT_POST, 'nombre', FILTER_SANITIZE_STRING);
$url = filter_input(INPUT_POST, 'web', FILTER_SANITIZE_URL);
?>

            
▶ Salida (simulada, con email="ana@mail.com" y edad=20)

          

          
⚠️
FILTER_SANITIZE_STRING está obsoleto desde PHP 8.1. Para sanitizar texto libre, combina validación explícita con htmlspecialchars() en la salida.

        

      


      

        
        

          

            
php

            
<?php
// Generar hash (automáticamente seguro)
$hash = password_hash("miClave123", PASSWORD_DEFAULT);

// Verificar contraseña
if (password_verify($passwordInput, $hash)) {
    echo "Contraseña correcta";
}

// Opcional: verificar si necesita actualización
if (password_needs_rehash($hash, PASSWORD_DEFAULT)) {
    $nuevoHash = password_hash($passwordInput, PASSWORD_DEFAULT);
    // Actualizar en BD
}
?>

            
▶ Salida (simulada)

          

          
🔒
Nunca guardes contraseñas en texto plano ni con md5()/sha1(). PASSWORD_DEFAULT usa bcrypt y añade sal automáticamente.

        

      


      

        
        

          

            
php

            
<?php
// Generar token (en sesión o en formulario)
session_start();
$_SESSION['csrf_token'] = bin2hex(random_bytes(32));

// En formulario
<input type="hidden" name="csrf_token" value="<?= $_SESSION['csrf_token'] ?>">

// Validar al procesar
if (!hash_equals($_SESSION['csrf_token'], $_POST['csrf_token'] ?? '')) {
    die("CSRF token inválido");

06
Bases de datos con PDO

      
Una única API para varios motores de BD, con consultas preparadas como defensa estándar contra la inyección SQL.


      

        
        

          

            
php

            
<?php
// Configuración (usar variables de entorno en producción)
$host = 'localhost';
$dbname = 'mi_base';
$user = 'root';
$pass = '';

try {
    $dsn = "mysql:host=$host;dbname=$dbname;charset=utf8mb4";
    $pdo = new PDO($dsn, $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
        PDO::ATTR_EMULATE_PREPARES => false  // Previene inyección SQL
    ]);
} catch (PDOException $e) {
    error_log("Error de BD: " . $e->getMessage());
    die("Error de conexión. Contacte con el administrador.");
}
?>

            
Requiere un servidor MySQL real — no simulable en este documento.

          

        

      


      

        
        

          

            
php

            
<?php
// SELECT con parámetros
$stmt = $pdo->prepare("SELECT * FROM usuarios WHERE id = :id");
$stmt->execute([':id' => $id]);
$usuario = $stmt->fetch();  // Un solo resultado

// SELECT con múltiples resultados
$stmt = $pdo->prepare("SELECT * FROM usuarios WHERE edad >= :edad");
$stmt->execute([':edad' => 18]);
$usuarios = $stmt->fetchAll();  // Todos los resultados

// INSERT
$stmt = $pdo->prepare("INSERT INTO usuarios (nombre, email) VALUES (:nombre, :email)");
$stmt->execute([
    ':nombre' => $nombre,
    ':email' => $email
]);
$idInsertado = $pdo->lastInsertId();

// UPDATE
$stmt = $pdo->prepare("UPDATE usuarios SET nombre = :nombre WHERE id = :id");
$stmt->execute([':nombre' => $nombre, ':id' => $id]);

// DELETE
$stmt = $pdo->prepare("DELETE FROM usuarios WHERE id = :id");
$stmt->execute([':id' => $id]);
?>

          

          
⚠️
Nunca concatenes variables directamente dentro del SQL. Los marcadores :nombre son lo que impide la inyección.

        

      


      

        
        

          

            
php

            
<?php
try {
    $pdo->beginTransaction();

    // Operaciones relacionadas
    $pdo->prepare("UPDATE cuentas SET saldo = saldo - :cantidad WHERE id = :origen")
        ->execute([':cantidad' => 100, ':origen' => 1]);

    $pdo->prepare("UPDATE cuentas SET saldo = saldo + :cantidad WHERE id = :destino")
        ->execute([':cantidad' => 100, ':destino' => 2]);

    $pdo->commit();  // Si todo OK, guardar
} catch (Exception $e) {
    $pdo->rollBack();  // Revertir todo
    error_log("Error en transacción: " . $e->getMessage());
}
?>

          

        

      

    


    
    

      
07
Gestión de estado: cookies y sesiones

      
HTTP no recuerda nada entre peticiones. Cookies y sesiones son las dos formas de fingir que sí lo hace.


      

        
        

          

            
php

            
<?php
// Crear cookie (expira en 30 días)
setcookie('preferencia', 'darkmode', time() + 30 * 24 * 60 * 60, '/');

// Leer cookie
$modo = $_COOKIE['preferencia'] ?? 'light';

// Eliminar cookie (poner expiración pasada)
setcookie('preferencia', '', time() - 3600, '/');
?>

            
Requiere un navegador real con cabeceras HTTP — no simulable en este documento.

          

        

      


      

        
        

          

            
php

            
<?php
// Iniciar sesión (siempre al principio)
session_start();

// Guardar datos
$_SESSION['usuario_id'] = 1;
$_SESSION['carrito'] = ['item1', 'item2'];

// Leer datos
$usuario = $_SESSION['usuario_id'] ?? null;

// Eliminar una variable
unset($_SESSION['carrito']);

// Destruir sesión completa
session_destroy();

// Configuración avanzada (personalizar duración)
ini_set('session.gc_maxlifetime', 3600);  // 1 hora
session_set_cookie_params(3600);           // Cookie de sesión
?>

            
👇 Prueba el concepto en vivo en el simulador de sesión, justo debajo.

Usos típicosPreferencias, recordar loginAutenticación, carrito compra

    php
    
            
    <?php
declare(strict_types=1);

class Usuario {
    // Propiedades tipadas (PHP 7.4+)
    private int $id;
    private string $nombre;
    private ?string $email = null;  // Nullable

    // Constructor (PHP 8+: promoción de propiedades)
    public function __construct(
        int $id,
        string $nombre,
        ?string $email = null
    ) {
        $this->id = $id;
        $this->nombre = $nombre;
        $this->email = $email;
    }

    // Métodos
    public function getNombre(): string {
        return $this->nombre;
    }

    public function setNombre(string $nombre): self {
        $this->nombre = $nombre;
        return $this;  // Permite encadenamiento
    }

    // Método estático (no necesita instancia)
    public static function crearInvitado(): self {
        return new self(0, 'Invitado');
    }
}

// Uso
$usuario = new Usuario(1, 'Ana', 'ana@email.com');
echo $usuario->getNombre();

$invitado = Usuario::crearInvitado();
?>

// Interface (contrato)
interface Autenticable {
    public function login(string $pass): bool;
}

    public function log(string $mensaje): void {

}

    Actividad 1
    Validador de DNI con cálculo de letra
    
        
    
          
          
          
        
    
        
    
          
    
            
    Crea una función que reciba un DNI (string), valide que tiene 8 dígitos, calcule la letra correspondiente y devuelva el DNI completo. Si es inválido, lanza una excepción.
    
            
    
              
              
              
    
            
    
          
    
          
    
            
    La letra se calcula con el módulo 23 sobre el número:
    
            
    php
    $letras = "TRWAGMYFPDXBNJZSQVHLCKE";
$letra = $letras[$numero % 23];
    
          
    
          
    
            
    
              
    
                
                Inténtalo primero con la pista de arriba
              
    
              
    
                
    php
    
                
    <?php
declare(strict_types=1);

function validarDNI(string $dni): string {
    // Limpiar entrada (quitar espacios)
    $dni = trim($dni);

    // Extraer número (primeros 8 dígitos)
    $numero = substr($dni, 0, 8);
    $letra = substr($dni, 8, 1);

    // Validar formato
    if (!preg_match('/^[0-9]{8}$/', $numero)) {
        throw new InvalidArgumentException("DNI debe tener 8 dígitos");
    }

    // Calcular letra
    $letras = "TRWAGMYFPDXBNJZSQVHLCKE";
    $letraCalculada = $letras[intval($numero) % 23];

    if ($letra && $letra !== $letraCalculada) {
        throw new InvalidArgumentException("Letra incorrecta");
    }

    return $numero . $letraCalculada;
}

// Uso
try {
    echo validarDNI("12345678Z");  // 12345678Z
    // echo validarDNI("1234567");   // Lanza excepción
} catch (InvalidArgumentException $e) {
    echo "Error: " . $e->getMessage();
}
?>

    Actividad 2
    Procesador de CSV con subida de archivo
    
        
    
          
          
          
        
    
        
    
          
    
            
    Crea un formulario que permita subir un archivo CSV con columnas (nombre, email, edad). Lee el archivo, valida que cada email sea correcto y muestra los datos en una tabla HTML. Si algún email no es válido, muestra error pero procesa el resto.
    
          
    
          
    
            
    Usa fopen(), fgetcsv() y filter_var() para validar el email.
    
          
    
          
    
            
    
              
    
                
                Inténtalo primero con la pista de arriba
              
    
              
    
                
    php
    
                
    <!-- subir_csv.php -->
<?php
$datos = [];
$errores = [];

if ($_SERVER['REQUEST_METHOD'] === 'POST' && isset($_FILES['csv'])) {
    $archivo = $_FILES['csv'];

    if ($archivo['error'] === UPLOAD_ERR_OK) {
        if (($handle = fopen($archivo['tmp_name'], 'r')) !== false) {
            // Saltar cabecera (si existe)
            $cabecera = fgetcsv($handle);

            while (($fila = fgetcsv($handle)) !== false) {
                list($nombre, $email, $edad) = $fila;

                // Validar email
                if (filter_var($email, FILTER_VALIDATE_EMAIL)) {
                    $datos[] = ['nombre' => $nombre, 'email' => $email, 'edad' => $edad];
                } else {
                    $errores[] = "Email inválido: $email";
                }
            }
            fclose($handle);
        }
    }
}
?>
<form method="post" enctype="multipart/form-data">
    <input type="file" name="csv" accept=".csv">
    <button>Subir y procesar</button>
</form>

<?php if ($errores): ?>
    <ul style="color:red">
        <?php foreach ($errores as $error): ?>
            <li><?= htmlspecialchars($error) ?></li>
        <?php endforeach; ?>
    </ul>
<?php endif; ?>

<?php if ($datos): ?>
    <table border="1">
        <tr><th>Nombre</th><th>Email</th><th>Edad</th></tr>
        <?php foreach ($datos as $fila): ?>
            <tr>
                <td><?= htmlspecialchars($fila['nombre']) ?></td>
                <td><?= htmlspecialchars($fila['email']) ?></td>
                <td><?= htmlspecialchars($fila['edad']) ?></td>
            </tr>
        <?php endforeach; ?>
    </table>
<?php endif; ?>

    Actividad 3
    Gestor de tareas con sesión (CRUD básico)
    
        
    
          
          
          
        
    
        
    
          
    
            
    Crea un gestor de tareas usando $_SESSION. Debe permitir: agregar tarea (con texto y prioridad: alta/media/baja), listar tareas, marcar como completada, y eliminar tarea.
    
            
    ▶
    Esta es exactamente la lógica que puedes probar en vivo en el simulador de sesión más arriba.
    
          
    
          
    
            
    Almacena las tareas como array de objetos en sesión: $_SESSION['tareas'] = [['texto' => '...', 'prioridad' => 'alta', 'completada' => false], ...]
    
          
    
          
    
            
    
              
    
                
                Inténtalo primero con la pista de arriba
              
    
              
    
                
    php
    
                
    <?php
session_start();

// Inicializar array si no existe
if (!isset($_SESSION['tareas'])) {
    $_SESSION['tareas'] = [];
}

// Procesar acciones
$accion = $_GET['accion'] ?? '';
$indice = $_GET['indice'] ?? null;

switch ($accion) {
    case 'agregar':
        $texto = $_POST['texto'] ?? '';
        $prioridad = $_POST['prioridad'] ?? 'media';
        if (!empty($texto)) {
            $_SESSION['tareas'][] = [
                'texto' => htmlspecialchars($texto),
                'prioridad' => $prioridad,
                'completada' => false
            ];
        }
        header('Location: ' . $_SERVER['PHP_SELF']);
        exit;

    case 'completar':
        if ($indice !== null && isset($_SESSION['tareas'][$indice])) {
            $_SESSION['tareas'][$indice]['completada'] = !$_SESSION['tareas'][$indice]['completada'];
        }
        header('Location: ' . $_SERVER['PHP_SELF']);
        exit;

    case 'eliminar':
        if ($indice !== null && isset($_SESSION['tareas'][$indice])) {
            array_splice($_SESSION['tareas'], $indice, 1);
        }
        header('Location: ' . $_SERVER['PHP_SELF']);
        exit;
}

// Mostrar tareas
$tareas = $_SESSION['tareas'];
?>
<!-- Formulario de agregar -->
<form method="post">
    <input type="hidden" name="accion" value="agregar">
    <input type="text" name="texto" placeholder="Nueva tarea" required>
    <select name="prioridad">
        <option value="baja">Baja</option>
        <option value="media">Media</option>
        <option value="alta">Alta</option>
    </select>
    <button>Agregar</button>
</form>

<!-- Lista de tareas -->
<ul>
    <?php foreach ($tareas as $indice => $tarea): ?>
        <li style="text-decoration: <?= $tarea['completada'] ? 'line-through' : 'none' ?>">
            <?= htmlspecialchars($tarea['texto']) ?>
            [<?= $tarea['prioridad'] ?>]
            <a href="?accion=completar&indice=<?= $indice ?>">
                <?= $tarea['completada'] ? 'Desmarcar' : 'Completar' ?>
            </a>
            <a href="?accion=eliminar&indice=<?= $indice ?>" onclick="return confirm('¿Eliminar?')">Eliminar</a>
        </li>
    <?php endforeach; ?>
</ul>
    
              
    
            
    
          
    
        
    
      
    

      
      
    
        
    Actividad 4
    Función con tipos estrictos y manejo de excepciones
    
        
    
          
          
          
        
    
        
    
          
    
            
    Crea una función dividirSeguro(int $a, int $b): float que devuelva la división de dos números. Si $b es 0, lanza una DivisionByZeroError personalizada. Si $a o $b no son enteros (con tipado estricto), lanza TypeError automáticamente.
    
          
    
          
    
            
    Usa declare(strict_types=1); y throw new Exception("Mensaje").
    
          
    
          
    
            
    
              
    
                
                Inténtalo primero con la pista de arriba
              
    
              
    
                
    php
    
                
    <?php
declare(strict_types=1);

class DivisionByZeroError extends Exception {}

function dividirSeguro(int $a, int $b): float {
    if ($b === 0) {
        throw new DivisionByZeroError("No se puede dividir entre cero");
    }
    return $a / $b;
}

// Prueba
try {
    echo dividirSeguro(10, 2);   // 5.0
    echo dividirSeguro(10, 0);   // Lanza excepción
} catch (DivisionByZeroError $e) {
    echo "Error matemático: " . $e->getMessage();
} catch (TypeError $e) {
    echo "Error de tipo: " . $e->getMessage();
} catch (Exception $e) {
    echo "Error general: " . $e->getMessage();
}
?>

    Actividad 5
    Login con hash de contraseña y protección de fuerza bruta
    
        
    
          
          
          
        
    
        
    
          
    
            
    Crea un sistema de login que:
    
            
    1. Registre usuarios con password_hash().
    
            2. Verifique con password_verify().
    
            3. Almacene intentos fallidos en sesión (máximo 3 intentos).
    
            4. Bloquee al usuario durante 5 minutos tras 3 fallos.
    
            5. Use CSRF para proteger el formulario.
    
          
    
          
    
            
    Usa $_SESSION['intentos'] y $_SESSION['bloqueo_hasta'].
    
          
    
          
    
            
    
              
    
                
                Inténtalo primero con la pista de arriba
              
    
              
    
                
    php
    
                
    <?php
session_start();

// Simulación de BD (array en sesión)
if (!isset($_SESSION['usuarios'])) {
    $_SESSION['usuarios'] = [
        'admin' => password_hash('1234', PASSWORD_DEFAULT)
    ];
}

// Inicializar control de intentos
if (!isset($_SESSION['intentos'])) {
    $_SESSION['intentos'] = 0;
}
if (!isset($_SESSION['bloqueo_hasta'])) {
    $_SESSION['bloqueo_hasta'] = 0;
}

// Verificar bloqueo
$ahora = time();
if ($_SESSION['bloqueo_hasta'] > $ahora) {
    die("Demasiados intentos. Espera " . ($_SESSION['bloqueo_hasta'] - $ahora) . " segundos.");
}

// Procesar login
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    // Validar CSRF (ejemplo simplificado)
    if (!hash_equals($_SESSION['csrf_token'] ?? '', $_POST['csrf_token'] ?? '')) {
        die("Token CSRF inválido");
    }

    $usuario = $_POST['usuario'] ?? '';
    $clave = $_POST['clave'] ?? '';

    if (isset($_SESSION['usuarios'][$usuario]) &&
        password_verify($clave, $_SESSION['usuarios'][$usuario])) {
        // Login exitoso
        $_SESSION['intentos'] = 0;
        $_SESSION['logueado'] = true;
        echo "✅ Bienvenido $usuario";
    } else {
        // Login fallido
        $_SESSION['intentos']++;

        if ($_SESSION['intentos'] >= 3) {
            $_SESSION['bloqueo_hasta'] = time() + 300; // 5 minutos
            die("❌ Demasiados intentos. Bloqueado 5 minutos.");
        }
        echo "❌ Usuario o contraseña incorrectos. Intento {$_SESSION['intentos']} de 3";
    }
}

// Generar token CSRF
$_SESSION['csrf_token'] = bin2hex(random_bytes(32));
?>
<form method="post">
    <input type="hidden" name="csrf_token" value="<?= $_SESSION['csrf_token'] ?>">
    Usuario: <input name="usuario"><br>
    Clave: <input type="password" name="clave"><br>
    <button>Entrar</button>
</form>
    
                
    El bloqueo depende de peticiones reales sucesivas — no simulable en este documento.
    
              
    
            
    
          
    
        
    
      
    

      
      
    
        
    Actividad 6
    Dashboard con conexión PDO (usuarios reales)
    
        
    
          
          
          
        
    
        
    
          
    
            
    Crea un script que:
    
            
    1. Conecte a una base de datos MySQL (tabla usuarios con: id, nombre, email, created_at).
    
            2. Muestre todos los usuarios en una tabla HTML.
    
            3. Permita filtrar por nombre usando LIKE (consulta preparada).
    
            4. Muestre el total de usuarios y fecha de la consulta.
    
          
    
          
    
            
    Usa $pdo->prepare("SELECT * FROM usuarios WHERE nombre LIKE :nombre") con % alrededor.
    
          
    
          
    
            
    
              
    
                
                Inténtalo primero con la pista de arriba
              
    
              
    
                
    php
    
                
    <?php
declare(strict_types=1);

// Configuración BD
$host = 'localhost';
$dbname = 'test';
$user = 'root';
$pass = '';

try {
    $pdo = new PDO("mysql:host=$host;dbname=$dbname;charset=utf8mb4", $user, $pass, [
        PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION,
        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC
    ]);
} catch (PDOException $e) {
    die("Error de conexión: " . $e->getMessage());
}

// Obtener filtro
$buscar = $_GET['buscar'] ?? '';

// Consulta preparada
$sql = "SELECT * FROM usuarios WHERE nombre LIKE :nombre ORDER BY created_at DESC";
$stmt = $pdo->prepare($sql);
$stmt->execute([':nombre' => "%$buscar%"]);
$usuarios = $stmt->fetchAll();

// Contar total
$total = count($usuarios);
?>
<h2>Dashboard de Usuarios (Total: <?= $total ?>)</h2>
<p>Última actualización: <?= date('Y-m-d H:i:s') ?></p>

<form method="get">
    <input type="text" name="buscar" placeholder="Filtrar por nombre" value="<?= htmlspecialchars($buscar) ?>">
    <button>Filtrar</button>
</form>

<table border="1">
    <tr>
        <th>ID</th>
        <th>Nombre</th>
        <th>Email</th>
        <th>Fecha Registro</th>
    </tr>
    <?php if ($usuarios): ?>
        <?php foreach ($usuarios as $usuario): ?>
            <tr>
                <td><?= $usuario['id'] ?></td>
                <td><?= htmlspecialchars($usuario['nombre']) ?></td>
                <td><?= htmlspecialchars($usuario['email']) ?></td>
                <td><?= $usuario['created_at'] ?></td>
            </tr>
        <?php endforeach; ?>
    <?php else: ?>
        <tr><td colspan="4">No se encontraron usuarios</td></tr>
    <?php endif; ?>
</table>
