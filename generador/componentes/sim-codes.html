Codigos de Estado HTTP — El Quiz

Haz clic en un escenario para abrirlo. Elige el codigo de estado HTTP correcto para cada situacion.

Recurso creado correctamente 1

Un cliente envia una peticion POST al endpoint /api/usuarios con los datos de un nuevo usuario en el body. El servidor crea el usuario en la base de datos y devuelve la respuesta.

Cliente no autenticado 2

Un cliente intenta acceder a /api/perfil sin enviar ninguna cabecera de autenticacion (ni token, ni sesion, ni cookie). El servidor rechaza la peticion.

Recurso no encontrado 3

Un cliente pide /api/productos/99999 pero no existe ningun producto con ID 99999 en la base de datos.

Servidor no disponible 4

El servidor de la API esta en mantenimiento. No puede atender ninguna peticion. Debe responder de forma que el cliente sepa que es temporal y debe reintentar.
