0.3 Comprobación del entorno (tu LEMP en Docker)

Damos por hecho que ya sabes levantar tu stack LEMP con docker compose y que una carpeta de tu equipo está montada como raíz web (dentro del contenedor suele ser /var/www/html). Los nombres de servicio (web, php…) dependen de tu docker-compose.yml: míralos con docker compose ps.

Paso 1. En la carpeta de tu proyecto ejecuta docker compose up -d. Después docker compose ps: el servicio web debe aparecer como running / Up.

Paso 2. Abre VS Code sobre la carpeta montada (la que se ve como raíz web dentro del contenedor). Crea la subcarpeta php-intro/.

Paso 3. Dentro, crea hola.php con este contenido exacto:

php
<?php
echo "¡Hola, mundo!";

Paso 4. Guarda (Ctrl+S). Comprueba que se llama hola.php, no hola.php.txt. En VS Code, abajo a la derecha, debe poner PHP.

Paso 5. Abre http://localhost:PUERTO/php-intro/hola.php, donde PUERTO es el que publicaste en el compose (por ejemplo 8080; si es el 80, se omite).

Paso 6. Debes ver ¡Hola, mundo! en pantalla, sin más.

Paso 7 (bonus). Ejecuta PHP directamente en el contenedor, sin navegador:

bash
docker compose exec web php -v
docker compose exec web php /var/www/html/php-intro/hola.php

  • echo imprime ese resultado en el mismo sitio donde estaba el <?php en el archivo original. El HTML resultante sale con la hora ya "pegada".

APensar como un programador (antes de teclear)

Programar es resolver un problema con instrucciones tan simples que una máquina las pueda seguir. Escribir PHP es la parte fácil; lo difícil (y lo importante) es saber qué instrucciones dar y en qué orden.

A.1 ¿Qué es un algoritmo?

Una receta: una lista ordenada y sin ambigüedades de pasos que lleva de unos datos de entrada a un resultado.

ALGORITMO hacer_te
  1. Llenar el cazo de agua
  2. Calentar el agua hasta que hierva
  3. Echar la bolsita en la taza
  4. Verter el agua
  5. Esperar 3 minutos
  6. Retirar la bolsita

Un ordenador es un cocinero muy obediente y nada listo: hace exactamente lo que dices, en el orden que dices. Si el paso 2 dice "hasta que hierva" sin más, no sabe cuándo parar. Por eso los algoritmos se escriben primero en pseudocódigo (español estructurado) y luego se traducen a PHP.

A.2 Las tres estructuras con las que se construye todo
Estructura Pregunta que responde En la receta En PHP
Secuencia ¿En qué orden? Paso 1, paso 2, paso 3… Una línea tras otra
Selección ¿Y si…? Si hay leche, añádela if / else / switch
Iteración ¿Cuántas veces? Mientras no hierva, espera while / for / foreach

Todo programa que verás en tu vida (un banco, un videojuego, WordPress) está hecho con estas tres piezas combinadas.

A.3 De pseudocódigo a PHP 
ALGORITMO decidir_descuento
  LEER importe
  SI importe > 100 ENTONCES
      descuento ← importe × 10 %
  SI NO
      descuento ← 0
  FIN SI
  ESCRIBIR importe − descuento
php
<?php
$importe = 120;
if ($importe > 100) {
    $descuento = $importe * 0.10;
} else {
    $descuento = 0;
}
echo $importe - $descuento;   // 108

Observa la correspondencia: ← es = · SI … ENTONCES es if (…) { · SI NO es } else { · ESCRIBIR es echo.

A.4 La traza: ejecutar el programa en tu cabeza

Trazar es seguir el programa línea a línea apuntando qué valen las variables en cada momento. Es la técnica nº 1 para encontrar fallos lógicos.

Paso Línea ejecutada $importe $descuento Salida
1 $importe = 120; 120 —
2 if ($importe > 100) → cierto 120 —
3 $descuento = $importe * 0.10; 120 12
4 echo $importe - $descuento; 120 12 108

Método de 4 pasos para cualquier problema:
① entiende qué entra y qué debe salir
② escribe los pasos en pseudocódigo
③ pruébalos a mano con un ejemplo (traza)
④ solo entonces, traduce a PHP.
En el laboratorio de trazas de abajo puedes ver cómo lo hace PHP paso a paso.

                    3.1 ¿Qué es una variable? (analogía)
                    

                        
Una variable es una caja etiquetada donde guardas un valor que puede
                            cambiar. La etiqueta es el nombre ($edad); el contenido es el valor
                            (25).

                        
   ┌──────────────┐
   │  $edad       │  ← etiqueta (nombre)
   ├──────────────┤
   │     25       │  ← contenido (valor)
   └──────────────┘

                        
Puedes abrir la caja (leer), meter otra cosa (asignar), tirar la caja a
                                la basura (unset).

                    

                

                

                    3.2 Declaración y tipos
                    

                        
En PHP no se declara el tipo: se asigna directamente y PHP lo deduce.

                        

                            
php

                            
<?php
$nombre = "Ana";        // string (texto)
$edad   = 25;           // int (entero)
$nota   = 7.5;          // float (decimal)
$activo = true;         // bool (verdadero/falso)
$nada   = null;         // null (sin valor)
?>

                        

                        
Para ver el tipo en tiempo de ejecución: var_dump($nombre); →
                            imprime string(3) "Ana". Muy útil para depurar.

                    

                

                

                    3.3 Interpolación de variables
                    

                        

                            
php

                            
<?php
$nombre = "Ana";

echo "Hola, $nombre";    // Hola, Ana   ← dobles comillas INTERPOLAN

8Funciones

                

                    8.1 ¿Por qué funciones? (analogía)
                    

                        
Si tienes que calcular el IVA en 20 sitios distintos, ¿copias la fórmula 20 veces? No: la
                            defines una vez y la reutilizas. Como una
                            receta que puedes invocar siempre que la necesites.
                        

                        

                            
php

                            
<?php
function calcularIva($precio, $tipo = 21) {
    $iva = $precio * $tipo / 100;
    return $precio + $iva;
}

echo calcularIva(100);       // 121 (IVA por defecto 21)
echo calcularIva(100, 10);   // 110 (IVA reducido)
?>

                        

                        
Partes:

                        

                            

                                
                                    

                                        Parte
                                        Ejemplo
                                        Significado
                                    

                                
                                
                                    

                                        Palabra clave
                                        function
                                        Declara la función
                                    

                                    

                                        Nombre
                                        calcularIva
                                        Verbo, sin tildes ni espacios
                                    

                                    

                                        Parámetros
                                        ($precio, $tipo = 21)
                                        Datos de entrada. $tipo tiene valor por defecto
                                    

                                    

                                        Cuerpo
                                        { ... }
                                        Lo que hace
                                    

                                    

                                        return
                                        return $precio + $iva;
                                        Devuelve el resultado
                                    

                                
                            

                        

                        

                            
return vs echo: echo
                                muestra por pantalla. return devuelve el
                                valor para que el código que llamó decida qué hacer. Una función puede
                                return y luego tú haces echo del resultado.
                            

                        

                    

                

                

                    8.2 Funciones integradas útiles
                    

                        

                            

                                
                                    

                                        Función
                                        Qué hace
                                        Ejemplo
                                    

                                
                                
                                    

                                        strlen($s)
                                        Longitud
                                        strlen("hola") → 4
                                    

                                    

                                        strtoupper($s)
                                        Mayúsculas
                                        strtoupper("hola") → "HOLA"
                                    

                                    

                                        strtolower($s)
                                        Minúsculas
                                        strtolower("HOLA") → "hola"
                                    

                                    

                                        ucfirst($s)
                                        Primera mayúscula
                                        ucfirst("hola") → "Hola"
                                    

                                    

                                        trim($s)
                                        Quita espacios extremos
                                        trim("  hola  ") → "hola"
                                    

                                    

                                        str_replace($a,$b,$s)
                                        Reemplaza
                                        str_replace("a","@","casa")
                                    

                                    

                                        strpos($s,$b)
                                        Posición de subcadena
                                        strpos("hola","o") → 1
                                    

                                    

                                        round($n,$d)
                                        Redondea
                                        round(3.1416,2) → 3.14
                                    

                                    

                                        rand($min,$max)
                                        Aleatorio entero
                                        rand(1,6) (dado)
                                    

                                    

                                        date($f)
                                        Fecha formateada
                                        date("d/m/Y")
                                    

                                    

                                        count($arr)
                                        Nº elementos
                                        count([1,2,3]) → 3
                                    

                                    

                                        number_format($n,$d,$sep_dec,$sep_mil)
                                        Formato numérico

                    Actividad9.1 — Validador de email
                            (simplificado)
                    

                        
Función validarEmail($email) que devuelva true si:

                        
    
                            
  • contiene @,
    • 
                            
  • tiene al menos un punto después de la @, con algún carácter entre ambos
                                (luis@.es no vale),
    • 
                            
  • no está vacío,
    • 
                            
  • no tiene espacios.
    • 
                        

                        
Pista: strpos($s, "@") devuelve la posición o
                            false. Ojo: si @ está en la posición 0, devuelve
                            0 (que en if es falso). Usa !== false.
                        

                        
Prueba con:

                        

                            
php

                            
$emails = ["ana@ies.es", "luis@.es", "sin arroba.es", "", "  pepe@dominio.org  "];

                        

                        

                            Ver solución
                            

                                

                                    
php

                                    
<?php
function validarEmail($email) {
    $email = trim($email);
    if ($email === "" || strpos($email, " ") !== false) { return false; }
    $arroba = strpos($email, "@");
    if ($arroba === false || $arroba === 0) { return false; }
    $punto = strpos($email, ".", $arroba);
    return $punto !== false && $punto > $arroba + 1;
}
$emails = ["ana@ies.es", "luis@.es", "sin arroba.es", "", "  pepe@dominio.org  "];
foreach ($emails as $e) {
    echo "[$e] → " . (validarEmail($e) ? "válido" : "NO válido") . "<br>";
}

                                

                                
Resultado: válido, NO, NO, NO, válido (tras trim).

                            

                        

                    

                

                

                    Ampliación9.1 — Sanitización con
                            htmlspecialchars
                    

                        
Prueba a mostrar <script>alert('hackeado')</script> con
                            echo directo y luego con htmlspecialchars(). ¿Qué diferencia hay?
